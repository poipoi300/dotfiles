Requires Wallpaper Engine (Steam app 431960) installed through Steam on Linux so
that `steamapps/common/wallpaper_engine/assets` exists, and the wanted
wallpapers subscribed/downloaded under `steamapps/workshop/content/431960`.
Edit `~/.config/linux-wallpaperengine/wallpaper.env` to pick the wallpaper.
Do not run alongside niri-wallpaper-engine, swaybg or mpvpaper on the same output.
