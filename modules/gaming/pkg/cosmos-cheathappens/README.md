Official download is scriptable (no form): the "Steam Deck" button on cheathappens.com/cosmos.asp links to
`download_cosmos.asp?cos=sd&dl=0`, which links straight to the zip used in `source=`. Unversioned URL, no upstream
checksum; the sha256 is pinned on first use. If makepkg reports a checksum mismatch, Cheat Happens changed the file:
inspect it before updating the hash.
